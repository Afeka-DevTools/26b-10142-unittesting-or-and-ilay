# תרגיל בית 2 - כתיבת בדיקות יחידה

**חברי הצוות:**
* עילאי
* אור

## הוראות הרצה:
1. ודאו שמותקן לכם Java ו-Gradle על המחשב (או השתמשו בסביבת ה-vLab).
2. פתחו את הטרמינל בתיקיית הפרויקט.
3. כדי להריץ את כל בדיקות היחידה, הקלידו את הפקודה הבאה:
   `./gradlew test` (בלינוקס/vLab) או `gradlew test` (בווינדוס).
4. בסיום ההרצה, תוכלו לראות את התוצאות בטרמינל ואת דוח הכיסוי בתיקיית `build/reports/tests/test/index.html`.
